# killbox weapons-first playtest

played `killbox.html` v7.9.1 from commit `d23caef`, which was titled `fixed some weapon descriptions`.

the loadout screen is doing useful work. individual items are clickable, the green checkmarks make inventory counts readable, and the `x` control for removing an item is immediately understandable.

the opening screen also lands well. the expedition map block diagram gives the mode a clear shape before the player starts.

## runs

the current tuning is tough in a way that feels closer to old arcade games than to quiet tower defense.

run one ended in under two minutes, around wave 8. the "last moments" flow was strong, and the death quote made the result feel authored instead of abrupt.

run two ended in about ninety seconds, again around wave 8. this was mostly a loadout-learning attempt.

one run tried to shelter the rift in the upper-right corner behind `+` blocks. a large enemy on the other side still seemed able to break the rift through the barrier, which made the terrain rule hard to read.

the longest run lasted about three minutes. at that point the game started to feel like an action roguelite loop: fast deaths, funny death lines, quick rethinking, and another attempt. showing exact survival time would support that loop.

## useful pressure

the pace makes hotkeys matter. left-hand access is important enough that mouse side-button mappings may become part of serious play.

the death screen's pulsing circles are memorable. the game already has a small ritual around losing, which suggests run history could be valuable. local storage for previous deaths, survival times, loadouts, and waves reached would make the player feel progress even across failed runs.

expedition mode currently reads less like tower defense and more like barrier placement plus arc emitter survival. that is not a bad thing. the chaos is compelling, but the pacing is intense enough that the mode needs to own the weapons-first identity clearly.

the strongest signal from this session: it is getting good, and the next major curiosity is how the exploring mode changes the rhythm.
