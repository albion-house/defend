# first playable

saltmarsh crossing is one small tower defense mission.

two paths bend toward a shared gate. players build on fixed pads. scripted waves make the pressure easy to read and repeat.

the current build has four tower types and five enemy types. the shapes are simple on purpose.

the important part is the loop:

1. build a defense.
2. start a wave.
3. earn gold.
4. keep the gate alive.
5. retry quickly.

the simulation uses explicit commands and fixed ticks. that keeps tests deterministic and leaves room for later multiplayer experiments.
