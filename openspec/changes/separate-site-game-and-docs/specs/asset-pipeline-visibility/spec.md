## REMOVED Requirements

### Requirement: Generated asset previews
**Reason**: Generated asset previews are not a required product surface for the current playable prototype.

**Migration**: Preserve useful asset notes or previews as optional, clearly labeled knowledge-garden content under `docs/`.

### Requirement: Atlas inspection stubs
**Reason**: Atlas inspection is speculative and should not be required before an asset pipeline exists.

**Migration**: Record atlas experiments under `docs/` when they become useful; create a later capability when observable tooling behavior is required.

### Requirement: Asset validation reports
**Reason**: Static asset-validation reports are not a current playable-product requirement.

**Migration**: Keep any useful validation observations with their knowledge-garden material until a real asset pipeline needs enforceable validation.

### Requirement: AI art pipeline integration path
**Reason**: A future AI art pipeline is speculative and should not constrain the current site architecture.

**Migration**: Keep AI art pipeline ideas under `docs/speculation/` until a later approved change defines an implementation contract.
