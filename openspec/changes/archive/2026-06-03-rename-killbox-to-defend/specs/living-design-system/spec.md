## MODIFIED Requirements

### Requirement: Token documentation
The site SHALL document visual tokens used by the Defend platform and prototype UI.

#### Scenario: Visitor inspects tokens
- **WHEN** a visitor opens the design-system route
- **THEN** the page SHALL show representative typography, color, spacing, surface, and component examples using the Defend brand

### Requirement: Mobile navigation
The site SHALL provide mobile navigation that preserves access to platform routes without overflowing the viewport.

#### Scenario: Visitor opens the site on a narrow viewport
- **WHEN** the viewport cannot fit all primary navigation links inline
- **THEN** the header SHALL show the Defend brand and a hamburger navigation control instead of rendering all primary links inline
