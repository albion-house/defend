## MODIFIED Requirements

### Requirement: Implementation plan documentation
OpenSpec SHALL define normative behavior and change acceptance criteria, while `defend-docs/` SHALL contain the canonical human-facing development instructions and background material.

#### Scenario: Implementation guidance is documented
- **WHEN** a change adds or revises development workflow instructions
- **THEN** normative requirements SHALL be captured in OpenSpec
- **AND** the human instructions SHALL be updated under `defend-docs/`
